# 错题本原型（网页版）

错题收集、练习、学习报告的网页原型，包含电脑端与手机端两套界面。

## 在线访问

部署在 GitHub Pages，push 到 `main` 分支后十几秒自动更新，**链接永久固定**。

| 端 | 地址 |
|---|---|
| 电脑 | `https://<用户名>.github.io/<仓库名>/` |
| 手机 | `https://<用户名>.github.io/<仓库名>/m.html` |

> 首次 push 后需在仓库 Settings → Pages 中确认 Source 为 **GitHub Actions**。

## 文件结构

```
index.html      电脑端（仓库根路径即主页）
m.html          手机端
```

两个文件都是单文件原型：HTML + CSS + JS 全部内联，无任何外部依赖、无构建步骤，双击即可在浏览器打开。

## 功能范围

- **年级 × 科目分区**：首页可切换年级（初一/初二/初三）与科目（数学/语文/英语/物理/化学）。错题、练习抽题、学习报告、导出打印全部按当前组合隔离，互不串数据；选择记录在本地浏览器，刷新后保持。
- **错题本**：按知识点归集，含掌握度标记与筛选。
- **练习**：基于薄弱知识点抽题，支持作答与结果反馈。
- **学习报告**：统计作答量、练习知识点数、错题数、连续天数。
- **导入 / 导出**：导入试卷错题，导出/打印当前范围的错题。

## 数据说明

内置示例数据仅覆盖「数学 · 初三」一组，其余 14 种组合为空。切换空组合时会显示引导卡片，导入试卷后会自动归集到当前年级与科目下。

所有数据存放在浏览器 `localStorage`，不上传服务器、不做账号同步。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```
